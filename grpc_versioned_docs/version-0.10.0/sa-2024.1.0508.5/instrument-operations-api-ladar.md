:::note[Not Available for SA 2024.1.0508.5]

Server 0.10.0 for SA 2024.1.0508.5 has no RPC for these commands, and no earlier

[SA 2026.1.0529.7 reference](/api/grpc/instrument-operations-api-ladar)
