## Get Last Instrument Index

<span className="catalog-status catalog-status--current">Current</span>

Returns both outputs exposed by the MP command: its integer instrument index
and its structured Collection/Instrument identity. Briosa does not infer one
value from the other.

## Rename Instrument

<span className="catalog-status catalog-status--current">Current</span>

Renames the selected instrument. SpatialAnalyzer remains the authority for
name validation, uniqueness, and the resulting live model state.

## Get Instrument ID from Name

<span className="catalog-status catalog-status--current">Current</span>

Looks up an instrument by its MP `Name` string and returns the corresponding
structured Collection/Instrument identity.

## Get Instrument Model

<span className="catalog-status catalog-status--current">Current</span>

Returns the instrument name and model string reported by SpatialAnalyzer for
the selected instrument.

## Move Instrument to Another Collection

<span className="catalog-status catalog-status--current">Current</span>

Moves the selected instrument into the named collection. Briosa does not cache
or preflight collection membership; each call operates on current SA state.

## Save Instrument Configuration

<span className="catalog-status catalog-status--current">Current</span>

Saves the selected instrument's configuration to the supplied `FileReference`.
The reference identifies a path accessible to the local Briosa server.

## Load Instrument Configuration

<span className="catalog-status catalog-status--current">Current</span>

Loads the selected instrument's configuration from the supplied
`FileReference`. The reference identifies a path accessible to the local
Briosa server.

## Export Instrument History to XML File

<span className="catalog-status catalog-status--current">Current</span>

Exports the selected instrument's history to an XML file at the supplied
`FileReference`.

## Point At Target

<span className="catalog-status catalog-status--current">Current</span>

Points the selected instrument at an existing target. An optional HTML prompt
file is supported, but omitted by default so Briosa does not introduce a prompt
that the caller did not request.

## Measure Single Point Here

<span className="catalog-status catalog-status--current">Current</span>

Measures the selected target with the selected instrument. `Measure
Immediately` retains the MP default of `false`, and the optional HTML prompt is
absent by default.

## Get Current Instrument Position Update

<span className="catalog-status catalog-status--current">Current</span>

Returns X/R, Y/Theta, Z/Phi, time since the update, and the approximate
timestamp reported by SA. The reporting frame defaults to `Instrument Base`;
Cartesian output is used unless the caller requests polar coordinates.

## 'Build' Target

<span className="catalog-status catalog-status--current">Current</span>

Guides measurement of a target relative to a nominal point. The component and
magnitude tolerances all default to disabled with values of zero, matching the
MP command. The optional HTML prompt is absent by default.

## Measure Existing Single Point

<span className="catalog-status catalog-status--current">Current</span>

Measures an existing target into a selected Point Group and returns the
resulting point identity. Immediate measurement defaults to `false` and the

<span className="catalog-status catalog-status--current">Current</span>

Sets that application-global value. Verification defaults to `false`; Briosa
does not cache or restore the prior setting.

## Set Remeasure Failed Checks Only

<span className="catalog-status catalog-status--current">Current</span>

Clears points from failed feature checks in the selected collection, locks out
passing checks, and starts trapping at the first failed check. Briosa adds no
confirmation, rollback, or inspection-state management.

## Associate Objects with Instrument

<span className="catalog-status catalog-status--current">Current</span>

Associates a supplied object list with the selected instrument. SA may report
partial success when only some objects are found.

## Disassociate Objects from Instrument

<span className="catalog-status catalog-status--current">Current</span>

Disassociates the supplied objects using the exact SA 2026.1 binding, which has
no Instrument ID input. The installed command-listing page claims that an
instrument input exists, but both the exact export and ObjectiveSA's binding
agree on the object-only shape.

## Make Collection Object Name Ref List from Objects associated with Instruments

<span className="catalog-status catalog-status--current">Current</span>

Queries live SA association state and returns the objects associated with the
supplied instruments. Unlike MP-only transient-list helpers, this command
retrieves information that the client cannot reconstruct locally.

## Combine Point Groups

<span className="catalog-status catalog-status--current">Current</span>

Creates a resulting Point Group that collects observations from commonly
measured points in the supplied groups. SA remains responsible for group
existence and combination behavior.

## Dissect Point Group

<span className="catalog-status catalog-status--current">Current</span>

Dissects a supplied Point Group into new groups using the caller-provided base
name. Briosa preserves the exact MP argument binding, including SA's misspelled
internal argument name, while exposing correctly spelled public fields.

## Synchronized Measurement (Master/Slave)

<span className="catalog-status catalog-status--current">Current</span>

Initiates synchronized measurement between a master and slave instrument. The
slave-group suffix defaults to `_Slave`, locating one instrument defaults to
`true`, locating the master rather than the slave defaults to `false`, and
waiting for completion defaults to `true`. A deadline or cancellation does not
prove that an in-progress SA measurement stopped.

## Create New Dynamic Reference

<span className="catalog-status catalog-status--current">Current</span>

Creates a dynamic reference from a selected instrument, defining points, and a
reference name. SA documents this operation specifically for AICON/Hexagon
MoveInspect systems, so licensed validation requires that specialized fixture.

## Calculate TCP Fixture Uncertainties

<span className="catalog-status catalog-status--current">Current</span>

Calculates a TCP Fixture uncertainty solution from the fixture, its transform
in the Working frame, and measured TCP points. The result preserves solution
validity, the refined transform, both six-component uncertainty vectors, RMS
and maximum errors, goodness of fit, robustness, and SA's result notes.

## Construct TCP Fixture

<span className="catalog-status catalog-status--current">Current</span>

Constructs a requested TCP Fixture and returns its resulting SA identity. Point
match threshold defaults to `0.0` and replacing an existing fixture defaults
to `false`. The installed command page inconsistently labels the resulting
fixture as an input and then claims there is no return value; the exact 2026.1
SDK export explicitly retrieves it as an output, which controls Briosa's
contract.

## Add Nominal Point to TCP Fixture

<span className="catalog-status catalog-status--current">Current</span>

Adds a named nominal point, location, and symmetric 3x3 uncertainty covariance
terms to a TCP Fixture. `Var XX`, `Var YY`, `Var ZZ`, `CoVar XY`, `CoVar XZ`,
and `CoVar YZ` each default to `0.0`.

## Get Last Solved TCP Fixture Uncertainty Covariance Matrix

<span className="catalog-status catalog-status--current">Current</span>

Returns the six-by-six covariance matrix from the fixture's last uncertainty
solution. Briosa represents the six MP row arrays as one typed matrix without
changing coordinate systems.

## Set Instrument Base Uncertainty Covariance Matrix WRT Base

<span className="catalog-status catalog-status--current">Current</span>

Sets an instrument's six-by-six base uncertainty covariance matrix with respect
to its Base frame. Briosa enforces only the required matrix shape and does not
judge symmetry, positive semidefiniteness, or the physical suitability of the
values.

## Set Instrument Base Uncertainty Covariance Matrix WRT WORLD

<span className="catalog-status catalog-status--current">Current</span>

Sets the corresponding matrix with respect to SA's WORLD frame under the same
shape-only contract.

## Get Instrument Base Uncertainty Covariance Matrix WRT WORLD

<span className="catalog-status catalog-status--current">Current</span>

Returns the selected instrument's six-by-six base uncertainty covariance
matrix with respect to the WORLD frame.

## Construct Measured Point Uncertainty Ellipsoids

<span className="catalog-status catalog-status--current">Current</span>

Constructs SA uncertainty ellipsoids for the supplied measured points. The
displayed uncertainty combines each measurement's uncertainty with its
instrument base uncertainty relative to the WORLD frame. SA reports failure
when points are missing or do not contain uncertainty data.

## Get WRTL Channel and Status

<span className="catalog-status catalog-status--current">Current</span>

Returns the selected WRTL instrument's connection status and active integer
channel. The exact export and ObjectiveSA agree on the binding; the installed
SA command listing does not provide a dedicated page for this operation.

## Set WRTL Channel

<span className="catalog-status catalog-status--current">Current</span>

Sets the selected WRTL instrument's integer channel. Channel defaults to `0`.
Briosa adds no range validation because the available exact-target evidence
does not establish valid channel limits.
