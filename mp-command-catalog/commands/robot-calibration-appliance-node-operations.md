## Add Calibration Appliance Node

<span className="catalog-status catalog-status--current">Current</span>

Adds a named Calibration Appliance Node to the live SA job.

## Delete Calibration Appliance Node

<span className="catalog-status catalog-status--current">Current</span>

Deletes the selected Calibration Appliance Node. Briosa intentionally adds no
dependency or usage preflight beyond the MP command's behavior.

## Connect/Disconnect Calibration Appliance Node

<span className="catalog-status catalog-status--current">Current</span>

Connects or disconnects the selected node. The exact MP default is to connect.

## Set Calibration Appliance Node Instrument

<span className="catalog-status catalog-status--current">Current</span>

Assigns an existing SA instrument to the selected Calibration Appliance Node.
The caller remains responsible for coordinating node, instrument, and hardware
state.

## Set Calibration Appliance Node Measurement Profile

<span className="catalog-status catalog-status--current">Current</span>

Sets the measurement-profile name for the selected node. The exact MP default
is an empty string.

## Set Calibration Appliance Node Measurement Target

<span className="catalog-status catalog-status--current">Current</span>

Sets the measurement-target name for the selected node. The exact MP default is
an empty string.

## Enable/Disable Calibration Appliance Node Instrument Auto Point

<span className="catalog-status catalog-status--current">Current</span>

Enables or disables instrument auto point for the selected node. The exact MP
default is enabled.

## Set Calibration Appliance Node Instrument Dwell Time

<span className="catalog-status catalog-status--current">Current</span>

Sets the measurement dwell time in seconds. Briosa passes the value through
without adding a range restriction; the exact MP default is `0.0`.

## Skip Calibration Appliance Node Measurement

<span className="catalog-status catalog-status--current">Current</span>

Advances the selected node past its current measurement. Briosa does not retain
or validate the node's workflow state before issuing the MP command.

## Set Calibration Appliance Node Measurement Frame

<span className="catalog-status catalog-status--current">Current</span>

Assigns an existing SA Frame as the node's measurement reference frame.

## Set Calibration Appliance Node Measurement Offset Transform

<span className="catalog-status catalog-status--current">Current</span>

Sets the node's measurement offset transform. Omitting the transform uses the
exact MP identity-transform default.

## Set Calibration Appliance Node Measurement Point Group

<span className="catalog-status catalog-status--current">Current</span>

Assigns an existing SA Point Group to the node's measurement workflow.

## Set Calibration Appliance Node Calibration Appliance IP Address

<span className="catalog-status catalog-status--current">Current</span>

Sets the calibration appliance address used by the selected node. The exact SA
2026.1 MP default is `0.0.0.0`. This configures hardware through the local SA
application; it does not enable remote Briosa execution.

## Set Calibration Appliance Node Trapping Node ID

<span className="catalog-status catalog-status--current">Current</span>

Sets the trapping node ID. Briosa passes the integer through without adding a
range restriction; the exact MP default is `0`.

## Enable/Disable Calibration Appliance Node Trap Manager

<span className="catalog-status catalog-status--current">Current</span>

Enables or disables the selected node's trap manager. The exact MP default is
enabled.

## Clear Calibration Appliance Node Trap Manager Requests

<span className="catalog-status catalog-status--current">Current</span>

Clears the selected node's trap-manager requests without Briosa retaining or
preflighting the node's workflow state.

## Set Calibration Appliance Node Integer Value

<span className="catalog-status catalog-status--current">Current</span>

Sets an integer value at the caller-selected index offset. The exact MP defaults
for both the offset and value are `0`; Briosa adds no bounds preflight.

## Get Calibration Appliance Node Integer Value

<span className="catalog-status catalog-status--current">Current</span>

Returns the integer value at the caller-selected index offset. The exact MP
offset default is `0`; Briosa adds no bounds preflight.

## Set Calibration Appliance Node Real Value

<span className="catalog-status catalog-status--current">Current</span>

Sets a real value at the caller-selected index offset. The exact MP defaults for
both the offset and value are `0`; Briosa adds no bounds preflight.

## Get Calibration Appliance Node Real Value

<span className="catalog-status catalog-status--current">Current</span>

Returns the real value at the caller-selected index offset. The exact MP offset
default is `0`; Briosa adds no bounds preflight.

## Set Calibration Appliance Node Data

<span className="catalog-status catalog-status--current">Current</span>

Sets the real-value data array exposed by the SA SDK. SA 2026.1 marks the MP
command's `Integer Values` input as unavailable through the SDK, so the Briosa
contract intentionally exposes only `Real Values` and documents that partial
coverage.

## Get Calibration Appliance Node Data

<span className="catalog-status catalog-status--current">Current</span>

Returns the real-value data array exposed by the SA SDK. The caller supplies the
expected real-value count because the SDK requires the output dimension in
advance. SA 2026.1 marks the `Integer Values` output as unavailable through the
SDK, so it is not part of this Briosa contract.

## Set Calibration Appliance Node Display Robot

<span className="catalog-status catalog-status--current">Current</span>

Assigns an existing SA Machine as the display robot for the selected node.

## Update Calibration Appliance Node Display Robot Joints

<span className="catalog-status catalog-status--current">Current</span>

Enables or disables display-robot joint updates. The exact MP default is
enabled.

## Get Calibration Appliance Node Status

<span className="catalog-status catalog-status--current">Current</span>

Returns whether the selected node reports its instrument and calibration
appliance as connected. This is a point-in-time SA status snapshot, not a
broader Briosa execution-readiness claim, and Briosa does not retain it.
