## Construct Point (Fit to Points)

<span className="catalog-status catalog-status--current">Current</span>

Fits a resulting point to a required Point Name list. Briosa passes the complete list to SpatialAnalyzer and preserves partial success when only part of the list resolves.

## Construct a Point in Working Coordinates

<span className="catalog-status catalog-status--current">Current</span>

Requires a Point Name and working-coordinate Vector. SpatialAnalyzer creates the point at that exact position.

## Construct Point From Survey Target Center

<span className="catalog-status catalog-status--current">Current</span>

Requires a source Cloud, reference seed Point, result Point, and search diameter. `Survey Target Type` supports `Triangle` and `Circle`, defaults to `Triangle`, and the diameter defaults to `0.0`.

## Set Point Position in Working Coordinates

<span className="catalog-status catalog-status--current">Current</span>

Mutates a required Point to a required working-coordinate Vector.

## Transform Points by Delta (About Working Frame)

<span className="catalog-status catalog-status--current">Current</span>

Mutates a required Point Name list by a required working-frame delta Vector.

## Construct a Point at line MidPoint

<span className="catalog-status catalog-status--current">Current</span>

Requires a source Line identity and a resulting Point Name.

## Construct Point Group from Point Name Ref List

<span className="catalog-status catalog-status--current">Current</span>

Requires a Point Name list and result Point Group. SpatialAnalyzer copies the resolved points and may report partial success when only part of the list resolves.

## Construct Point Groups from Vector Groups

<span className="catalog-status catalog-status--current">Current</span>

Requires a Vector Group list. Suffix defaults to an empty string, begin-point and end-point creation both default to `false`, and the created Point Group identities are returned.

## Construct Point Group from Point Cloud

<span className="catalog-status catalog-status--current">Current</span>

Requires source Cloud and result Point Group identities. Defaults are prefix `pt`, starting number `0`, offset `0.0`, subsampling `false`, subsampling distance `0.5`, and show progress `false`. The exact SDK argument is `Sub-Sampling?`.

## Construct Point From Cloud Point - Runtime Select

<span className="catalog-status catalog-status--current">Current</span>

Prompt defaults to `Select cloud point`, point construction defaults to `false`, and the constructed Point Name uses the MP empty identity when omitted. The selected cloud-point coordinates are returned.

## Construct a Point at Circle Center

<span className="catalog-status catalog-status--current">Current</span>

Requires a Circle identity and resulting Point Name.

## Construct Point at Intersection of Planes

## Construct Point at Intersection of Two Lines

## Construct Point at Intersection of Plane and Line

## Construct Point at intersection of B-Spline and Surfaces

## Construct Points at Intersection of Circle and Line

## Construct Points at Intersection of Principle Object Axes and Surfaces
