# Contributing

Thanks for helping make Briosa easier to use.

## Before opening a pull request

1. Start from an issue on the
   [Briosa Roadmap & Delivery project](https://github.com/orgs/spatialanalyzer/projects/1)
   or open a focused issue in this repository.
2. Create a short-lived branch named `<issue-number>-<short-description>`.
3. Keep API and runtime claims aligned with committed source in
   [spatialanalyzer/briosa](https://github.com/spatialanalyzer/briosa).
4. Use your own words. Do not copy vendor documentation or include proprietary
   binaries, screenshots, licensed data, paths, or credentials.
5. Run `npm ci` and `npm run check` with Node.js 24.

Use `Closes #<issue-number>` only when the pull request satisfies the issue.
Use `Refs #<issue-number>` for partial work.

Organization-wide policies and unresolved contribution questions live in the
[governance repository](https://github.com/spatialanalyzer/governance).
