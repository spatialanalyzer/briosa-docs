# Briosa Brand Assets

These files are copied unchanged from
[`spatialanalyzer/briosa-brand@v1`](https://github.com/spatialanalyzer/briosa-brand/tree/v1),
commit `0a86718f66164e4a773bea37f738888a57c6bce0`.
The directory structure preserves the original asset paths:

- `colors.css`: the five approved brand colors.
- `icons/favicon.svg`: browser icon.
- `logos/briosa-horizontal-inverse.svg`: footer identity.
- `logos/briosa-stacked-inverse.svg`: homepage identity.
- `suite/briosa-{docs,server,dotnet,python,js}-{color,inverse}.svg`:
  navigation and product reference identities.
- `fonts/Inter-Variable.ttf` and `fonts/OFL.txt`: original Inter font and license.
- `LICENSE` and `THIRD-PARTY-NOTICES.md`: original license and attribution.

Follow the [brand guide](https://github.com/spatialanalyzer/briosa-brand/blob/v1/BRAND-GUIDE.md)
when updating these assets. Copy from a reviewed release, preserve the SVG
artwork and aspect ratios, and update this provenance record. The site builds
and serves its own copies without fetching the brand repository or a font CDN.

The approved slogan retains its exact wording and casing:
“SpatialAnalyzer integration, simplified.”
